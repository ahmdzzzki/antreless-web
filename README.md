# Antreless Web

Official website for **Antreless**.

Antreless is a queue and ordering platform that helps customers order more conveniently, monitor their queue, and pick up their order when it is ready.

## Website

https://antreless.cloud

## Project Structure

- `index.html` — Main landing page
- `privacy.html` — Privacy Policy
- `account-deletion.html` — Account deletion information
- `assets/` — Shared styles, scripts, and visual assets

## Local Development

This is a static website and does not require a build process.

Run:

```bash
python3 -m http.server 8000
